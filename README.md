# Datapack Quirks

This datapack is a companion to the Datapack Quirks panel presented at [Smithed Summit 2026](https://smithed.net/summit) by Moxvallix.

It is made for Minecraft 26.2.

This pack collects the main quirks presented in the panel, and aims to show off how they work to anyone curious.
Every quirk is numbered and named, and all of the code is commented to hopefully explain how it all works.

To get started, head to the `data/quirks/function` folder and check out the different quirks.
To test a quirk, run the function in game with the function command.
Most quirks assume they are being run by a player at the player.

To get started, either clone down the repo, or download the latest version from the [releases tab](https://github.com/moxvallix/datapack-quirks/releases).
